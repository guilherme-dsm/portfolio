Mini Rede ABM

Em produção

Mini rede social voltada para moradores de um condomínio, desenvolvida do zero como aprendizado prático de full-stack: API REST, autenticação com hash de senha, upload de arquivos e recuperação de senha por e-mail. Combina páginas server-rendered (Flask + Jinja2) com um mural client-rendered (JavaScript vanilla + Fetch API), sem frameworks de frontend e sem ORM — priorizando entender cada camada antes de abstrair.

  • Python
  • Flask
  • Jinja2
  • PostgreSQL
  • JavaScript

MailTriage

Em desenvolvimento

Sistema de triagem inteligente de e-mail: o usuário define regras exatas ou semânticas sobre o que é relevante, o n8n monitora a caixa do Gmail em tempo real e aplica as regras — com apoio de um LLM quando é preciso entender o conteúdo do e-mail — organizando tudo num painel próprio por categoria. Backend REST em Node/TypeScript, banco relacional no Neon e frontend em React ainda por vir.

  • Node.js
  • TypeScript
  • Express
  • PostgreSQL
  • n8n
  • React
